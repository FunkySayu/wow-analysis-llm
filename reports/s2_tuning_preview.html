Arcane Mage · 12.1 Live · Season 2 tuning preview

The compensation buff doesn't compensate.

Blizzard's August 18 class tuning post nerfs the Venomous Abyss tier set and adds a flat baseline buff to make up for it. Simulated against Funkywand's current gear, the trade isn't even: DPS drops about 4.6% once the change lands, because the tier bonuses being cut are worth more to this gear than the baseline buff gives back.

Character Funkywand · Dwarf · ilvl 321 avg Fight Patchwerk, single target, optimal_raid Iterations 50,000 per run Rotation simc default Arcane APL

What's changing

Three edits, effective August 18

Posted by class balance developer Linxy on August 14. The stated intent: the Venomous Abyss set bonus is overperforming its tuning target, so it's cut — with a baseline damage increase meant to limit the net loss to something smaller than the set-bonus cut itself.

The baseline row is the part worth double-checking yourself: it reads as "+3%" in the post, but the passive it lands on was already sitting at +8% from earlier Season 2 hotfixes, so the applied value is +11%, not a fresh +3% aura.

Reading it

What this does and doesn't tell you

01

The set bonus was worth more than the compensationfinding

The 2-set alone was giving Arcane Missiles a flat +20% — a bigger single number than anything else in the kit gets from tier. Cutting it to +5% and handing back 3 baseline percentage points doesn't come close to break-even for a profile leaning this hard on Missiles casts.

02

Not live yetcaveat

Posted August 14, effective August 18. As of this run neither the live game nor simc's vendored data (build 12.1.0.69299, hotfix dated August 15) reflects it — the "after" numbers come from patching the spell data in memory for this run only (see Method), not from an official update. Treat this as a preview of the stated intent, not a guarantee of the shipped values.

03

Default APL, not your addon rotationcaveat

The character string from the WCL addon export carries gear, talents, and consumables — it has no actions= list. Both runs used simc's bundled community Arcane APL, identical between the two, so the −4.6% is isolated to the tuning change. It is not necessarily what your own play would lose.

Net read

If this hotfix ships as posted, expect roughly a 4–5% DPS loss on this gear — worth re-simming once it's confirmed live, since a same-day follow-up tuning pass is common if the community pushes back on a nerf this size.

Reproducing this

How the change was applied

No source edit or rebuild — simc has a built-in override.spell_data mechanism that patches spell data in memory for a single run. Each value above was traced to its real spell/effect id first (via spell_query against the live client data), then overridden and re-verified with the same query before the "after" sim ran.

# after-tuning run, from a vendor/simc build at commit bb8107ca22 simc.exe funkywand_arcane.simc iterations=50000 fight_style=Patchwerk optimal_raid=1 \ override.spell_data=effect.1319720.base_value=5 # 2-set: 20 -> 5 override.spell_data=effect.1319740.base_value=3 # 4-set: 5 -> 3 override.spell_data=effect.179704.base_value=11 # baseline direct dmg: 8 -> 11 override.spell_data=effect.191116.base_value=11 # baseline periodic dmg: 8 -> 11

The "before" run is the same command with the four override.spell_data lines removed.
